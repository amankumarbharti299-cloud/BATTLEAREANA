# BattleHub

Original Free Fire tournament platform MVP. It includes tournament browsing, joining with a virtual wallet, player matches, leaderboard, and an admin tournament creator. This is an offline demo and does not process real-money payments or bypass any game terms.

## Run

```powershell
python -m http.server 8080
```

Open `http://localhost:8080`. For Android installation, serve over HTTPS and use Chrome's "Install app" option. Real payment gateways require provider, KYC, age, and regional compliance review.
